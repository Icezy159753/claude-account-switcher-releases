# Claude Account Switcher: ไฟล์โปรแกรม

repo นี้เก็บเฉพาะไฟล์ `ClaudeAccounts.exe` ของแต่ละเวอร์ชัน โปรแกรมที่ติดตั้งไว้แล้วจะเช็กและโหลดอัปเดตจากที่นี่เอง

**ดาวน์โหลด:** [เวอร์ชันล่าสุด](../../releases/latest) แล้วเปิด `ClaudeAccounts.exe` ได้เลย

- แต่ละ Release มีไฟล์ `ClaudeAccounts.exe.sha256` ไว้ตรวจว่าไฟล์ครบและไม่ถูกแก้ โปรแกรมตรวจให้เองก่อนติดตั้งอัปเดต
- ไฟล์ยังไม่มีลายเซ็นดิจิทัล ถ้า Windows เตือน "Windows protected your PC" ให้กด **More info → Run anyway**
- โปรแกรมนี้เป็นโปรเจกต์ส่วนตัว ไม่เกี่ยวข้องกับ Anthropic
